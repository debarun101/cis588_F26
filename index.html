From intuition to implementation.

This is a hands-on course where you will build and train neural networks entirely from scratch in Python. Starting from a single neuron, you will implement forward and backward propagation yourself using NumPy, work through the mathematics behind the ideas, and code the techniques that power modern AI systems.

1

Start with intuition

Develop a clear mental model of what each concept is doing and why it matters.

2

Understand the concept

Connect the intuition to the formal ideas used in neural-network training.

3

Work through the mathematics

Use gradients, derivatives, and the chain rule to understand learning at a deeper level.

4

Implement it in Python

Translate each idea into working NumPy code so you can see exactly how the pieces fit together.

What you'll learn

By the end of the semester, you should be able to move beyond using a framework and explain how the machinery underneath it actually works.

  • Build and train multi-layer neural networks from scratch using NumPy.
  • Implement forward and backward propagation using gradients and the chain rule.
  • Apply neural networks to real-world problems through hands-on course assignments.
  • Compare optimization methods including ADAM, Adagrad, RMSProp, and Momentum.
  • Use regularization techniques including L1/L2 and dropout.
  • Understand the structure and applications of common deep-learning architectures.
